# Контроль доступа

## Принцип
Доступ предоставляется по принципу минимально необходимых привилегий и только для рабочей цели.

## Жизненный цикл
Запрос, согласование, предоставление и отзыв доступа должны проходить через контролируемые корпоративные процессы. Временный доступ ограничивается согласованным сроком.

## Изменение роли
При переводе сотрудника между командами руководитель инициирует пересмотр доступов. При увольнении доступы отзываются в рамках процесса offboarding.
