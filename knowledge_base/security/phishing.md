# Фишинг и подозрительные сообщения

## Признаки
Подозрительными признаками являются неожиданные запросы пароля или кода подтверждения, срочность, необычный адрес отправителя, ссылка на незнакомый домен и неожиданные вложения.

## Действия
Не переходите по ссылке и не вводите учётные данные. Если письмо открыто, не отвечайте отправителю и передайте сообщение в Security через корпоративный канал.

## Если данные уже введены
Немедленно сообщите в Security и IT, смените пароль через утверждённый процесс и следуйте инструкциям по защите учётной записи.
