# Политика паролей

## Требования
Корпоративный пароль должен быть уникальным, не использоваться в личных сервисах и не передаваться другим людям. Рекомендуется использовать длинную парольную фразу, если система её поддерживает.

## Хранение
Пароли нельзя хранить в открытом виде в документах, чатах, заметках или исходном коде. Для поддерживаемых сценариев используется корпоративный менеджер паролей.

## Компрометация
При подозрении на раскрытие пароля его необходимо немедленно изменить и сообщить в Security, если компрометация связана с фишингом или другим инцидентом.
