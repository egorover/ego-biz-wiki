# Запрос доступа к корпоративным системам

## Порядок
Доступ запрашивается через корпоративный портал заявок. В заявке указываются система, требуемая роль, рабочая цель и срок, если доступ временный.

## Согласование
Запрос согласует руководитель сотрудника. Для систем с повышенными привилегиями требуется дополнительное согласование владельца системы или Security.

## Срочный доступ
Срочный доступ допускается только при наличии производственной необходимости и оформляется через тот же контролируемый процесс. Передача чужих учётных данных не является допустимой заменой заявки.
