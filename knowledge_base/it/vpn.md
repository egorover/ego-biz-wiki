# Подключение к корпоративному VPN

## Назначение
Корпоративный VPN используется для безопасного доступа к внутренним системам из внешней сети.

## Подключение
1. Установите утверждённый IT-клиент VPN на корпоративное устройство.
2. Войдите с корпоративной учётной записью.
3. Выберите профиль EgoTech Corporate.
4. Убедитесь, что клиент показывает защищённое подключение.

## Проблемы
Если подключение не устанавливается, не отключайте защитные средства самостоятельно. Зафиксируйте текст ошибки и обратитесь в IT Service Desk. При подозрении на компрометацию учётных данных дополнительно действуйте по процедуре Security.
