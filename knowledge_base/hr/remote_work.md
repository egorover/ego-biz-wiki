# Удалённая работа

## Условия
Удалённая работа разрешена для должностей, для которых такой режим согласован с руководителем. Сотрудник должен иметь стабильное подключение к интернету и использовать корпоративное устройство или утверждённую рабочую среду.

## Доступ
Для подключения к внутренним системам вне офиса используется корпоративный VPN. Учётные данные нельзя передавать другим людям.

## Рабочее время
Правила рабочего графика сохраняются и при удалённой работе. Изменение рабочего времени заранее согласуется с руководителем.
