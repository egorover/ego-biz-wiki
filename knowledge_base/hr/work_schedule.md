# Рабочий график

## Стандартный режим
Базовый рабочий график — пять рабочих дней в неделю, с понедельника по пятницу. Основное время доступности команд — с 10:00 до 18:00 по московскому времени.

## Перерывы
Сотрудник самостоятельно планирует перерыв в течение рабочего дня так, чтобы сохранять доступность для обязательных встреч и задач команды.

## Изменения
Индивидуальные изменения графика согласуются с руководителем. Для удалённой работы также действуют правила, описанные в документе remote_work.
