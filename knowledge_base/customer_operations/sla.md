# SLA для клиентских обращений

## Приоритеты
P1 — критическая недоступность ключевого сервиса; P2 — существенное нарушение работы части пользователей; P3 — ограниченная проблема без критического влияния; P4 — запрос или консультация.

## Время реакции
Для P1 целевое время первичной реакции — 30 минут, для P2 — 2 часа, для P3 — 8 рабочих часов, для P4 — 1 рабочий день. Это внутренние демонстрационные значения EgoTech Solutions.

## Контроль
Оператор фиксирует время получения, приоритет, действия и коммуникации. При риске нарушения SLA применяется процедура escalation.
